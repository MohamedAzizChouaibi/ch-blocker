# ch-blocker

**ch-blocker** is a simple Python-based website blocker that provides both a **graphical user interface (GUI)** and powerful functionality to block websites either **temporarily** or **permanently** by editing the system's `hosts` file.

---

## ✨ Features

- ✅ Block websites temporarily (e.g., for productivity sessions)
- 🔒 Block websites permanently (until manually unblocked)
- 🖥️ Easy-to-use graphical interface
- ⚙️ Automatically edits system `hosts` file to enforce blocking
- ⏰ Scheduled unblock option (for temporary blocks)

---

## 🚀 Getting Started

### 🔧 Requirements

- Python 3.7+
- Admin/root privileges (required to edit the hosts file)
- OS: Windows / Linux / macOS
